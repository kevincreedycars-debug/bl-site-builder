# How to reply to the owner

Someone running this portfolio reads a phone between other things. A reply that
takes a minute to understand has failed, however accurate it is.

## The shape

- At most three bullets. If there are four things to say, one of them waits.
- Each bullet says what is true now, then what it means. No bullet is a label.
- Plain words. "The link is gone and the buyer has not been told" beats
  "placement integrity issue detected".
- No file paths, no function names, no commands. Those belong in the notes, not
  in the message.
- Never say a thing is "done". Say what now works and how it was checked, or say
  what is still missing.

## Words that earn their place

| Instead of | Write |
|---|---|
| in progress | what has happened so far, and the next step |
| completed | what now works, and what was checked |
| error / issue | what happened, in the words a person would use |
| 100% / all green | the number, and what it covers |
| robust / seamless | nothing. Delete it |
| leverage, optimise, streamline | the actual verb |

## What a reply must include

- The one thing that changed, if something changed.
- The one thing that is still open, if something is.
- Nothing else, unless it changes what the reader should do next.

## What a reply must not do

- Claim a result it did not verify. If it was not run, say it was not run.
- Bury a problem under good news. Problems go first, in plain language.
- Ask more than one question at a time. A question that arrives with four others
  gets answered last.
- Use a question to avoid a decision that could be made and stated.

## Example

Three things, and one question:

- The dashboard now shows all eight pages from the data files. The test that
  draws each page passes, and so does a check that fetches them over the local
  server.
- Two links that were sold as live are returning an error. One of them the whole
  site is down, so the link cannot be confirmed either way; the other is a 404
  and needs replacing or refunding.
- Nothing is scheduled yet, and nothing sends mail from here.

One question: when a link comes back 404, do you replace it on the same site or
refund and move the buyer elsewhere? The wording I send the buyer depends on the
answer.

Short, true, and it ends on the thing that needs a person.
